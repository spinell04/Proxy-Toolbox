# Tools

The nine tools that make up Proxy Toolbox, in menu order. **Site Request Test** and **Monitor** are submenus of two tools each.

* [IP Uniqueness Test](ip-uniqueness-test.md) — check exit IPs and detect duplicates
* **Site Request Test** — full page requests:
  * [TM Request Tester](tm-request-tester.md) — Ticketmaster
  * [Bayern Tester](bayern-tester.md) — fcbayern.com/de/tickets
* **Monitor** — the two long-running watchers:
  * [Downtime Monitor](proxy-monitor.md) — continuous reachability monitoring with Discord webhook alerts
  * [Session Monitor](session-monitor.md) — alerts when a proxy’s exit IP changes
* [Ping Test](ping-test.md) — latency tests via TCP, HTTP, or HTTPS
* [Randomize File](randomize-file.md) — shuffle proxy order in a file
* [Proxy Parser](proxy-parser.md) — convert between proxy formats
* [Compare Results](compare-results.md) — local dashboard for comparing exported CSVs
